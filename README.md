REINFORCEMENT_LEARNING

## Setup
pip install -r requirements.txt

How to execute the code:

- main.py:
Trains SARSA and Q-learning in the Gridworld envrironment

- run_cliff.py
Trains both algorithms in the Cliff Walking environment

- optuna_tuning.py
Tunes the hyperparameters of both algorithms with Optuna in the four environments
and compares them against the default values
